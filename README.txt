РАСКЛАДКА by mysik
==================

Напечатал «ghbdtn», а хотел «привет»? Нажми одну клавишу, и программа
сама сотрёт слово, напечатает его правильно и переключит раскладку.

Горячие клавиши
---------------
Вариант «Классика» (как в Punto Switcher):
• Pause — исправить последнее напечатанное слово (или фразу);
• Shift + Pause — исправить выделенный текст.

Вариант «Для ноутбуков» (если нет клавиши Pause):
• Shift два раза подряд — исправить последнее слово;
• Ctrl два раза подряд — исправить выделенный текст.

Всегда работают:
• Ctrl + Alt + T — транслит выделенного: privet ⇄ привет;
• Ctrl + Alt + R — регистр выделенного: «пРИВЕТ» (забыл про Caps Lock) → «Привет».

Нажал случайно? Нажми ещё раз — слово вернётся обратно.

Работает в любых программах: браузере, Telegram, Discord, Word, играх.
Не работает только в окнах, запущенных от имени администратора
(так устроена защита Windows).


Сборка и запуск
---------------
1. Распакуй архив и проверь, что все файлы лежат рядом
   (Raskladka.cs, Shell.cs, MainWindow.xaml, Theme.xaml, app.ico,
   app.manifest). Запусти build.bat.
2. Запусти Raskladka.exe. Права администратора не нужны.
3. Включи «Запускать вместе с Windows» — программа будет тихо работать в трее.

Закрытие окна прячет программу в трей. Выход — правый клик по значку у часов.
